# Supabase

1. Crie um projeto no Supabase.
2. Rode a migration em `supabase/migrations/20260604124500_initial_schema.sql`.
3. Copie URL e anon key para `app/.env` usando `app/.env.example` como base.
4. Mantenha RLS ativo em todas as tabelas.

As tabelas iniciais sao `profiles`, `vehicles`, `scan_sessions`, `live_readings`, `dtc_codes`, `reports` e `vehicle_fingerprints`.
