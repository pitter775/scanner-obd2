# ELM327

Comandos usados na base:

```text
ATZ
ATE0
ATL0
ATS0
ATH0
ATSP0
0100
```

PIDs iniciais:

```text
010C RPM
010D velocidade
0105 temperatura do motor
0104 carga do motor
0111 posicao da borboleta
010F temperatura do ar
010B pressao do coletor
0142 tensao do modulo
```

DTCs:

```text
03 armazenados
07 pendentes
0A permanentes
04 apagar
```

Filtro inicial de identificacao:

```text
ATDPN protocolo ativo
0902 VIN
0904 Calibration ID
0906 CVN
090A ECU name
0100 PIDs suportados 01-20
0120 PIDs suportados 21-40
```
